# VioletCore v0.9.0 Plan — Engine Stats Provider API

Goal: make Engine Plugin observability extensible.

## Delivered

- `EngineStatsProvider` public API.
- Automatic stats provider registration when an Engine Plugin implements the interface.
- Provider lines shown in `/violetcore stats`.
- Provider reset called by `/violetcore resetstats`.
- SmartEntityTick v1.1.0 with internal counters.

## Why this matters

Performance plugins must be measurable. Core counters show hook activity, while provider stats show plugin-specific work.

## Next

v0.9.0 should add a build/release workflow that publishes server jar, API jar, checksums, and official Engine Plugins automatically.
