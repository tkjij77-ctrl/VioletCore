# VioletCore v0.5.0 Plan — Stability Beta

Goal: move VioletCore from MVP toward beta-quality server software by improving observability, versioning, and performance-plugin metrics.

## Scope

### 1. Release versioning in server output

- Add support for `VIOLETCORE_RELEASE=v0.5.0` during build.
- Make generated project/server version include `26.2-v0.5.0` instead of `local-SNAPSHOT`.
- Keep compatibility with normal Purpur `BUILD_NUMBER` builds.

### 2. Engine Plugin runtime statistics

Add internal stats for entity tick controllers:

- controller checks
- controller skipped entity ticks
- total skips
- per-plugin skips

Expose with:

```text
/violetcore stats
```

### 3. SmartEntityTick v1.1.0

- Ship official plugin as `SmartEntityTick-1.1.0.jar`.
- Keep safe defaults.
- Let VioletCore core count skipped ticks.

### 4. Release validation

- Compile server.
- Build runnable jar.
- Smoke test startup with SmartEntityTick.
- Verify:
  - `/violetcore status`
  - `/violetcore config`
  - `/violetcore stats`
  - `/violetcore hooks`
  - clean shutdown

## Non-goals

- No Mixins yet.
- No chunk IO changes.
- No gameplay-changing default behavior for animals/monsters.
