# VioletCore v0.6.0 Plan — Engine Runtime Stats

Goal: add first-class observability for Engine Plugin performance hooks.

## Delivered

- `/violetcore stats`
- `/violetcore resetstats`
- EntityTickController check counter
- EntityTickController skip counter
- Per-plugin skip counters
- Crash-report stats details

## Why this matters

A performance-oriented server software must be observable. Engine Plugins should not silently change gameplay or performance. Server owners need to see whether a controller is actually doing work.

## Next

v0.7.0 should expose more detailed SmartEntityTick stats by entity type and add a small benchmark/smoke-test workflow.
