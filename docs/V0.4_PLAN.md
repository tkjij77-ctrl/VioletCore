# VioletCore v0.4.0 Plan — Performance Core

Goal: make the server software more launch-ready by adding a stable Engine Plugin configuration layer and the first official optional performance Engine Plugin.

## Scope

### 1. Core Engine Plugin configuration

Add a root config file:

```text
engine-plugins.yml
```

Planned keys:

```yaml
engine-enabled: true
strict-version-check: true
warn-undeclared-entity-controller: true
fail-fast-on-plugin-error: false
debug-logging: false
disabled-plugins: []
```

Features:

- Created automatically on first boot.
- Loaded before scanning `engine-plugins/`.
- Supports disabling the entire Engine Plugin system.
- Supports disabling specific Engine Plugins by name.
- Runtime command to reload config without reloading Engine Plugins.

### 2. `/violetcore` command improvements

Add:

```text
/violetcore config
/violetcore reloadconfig
```

### 3. Official optional performance Engine Plugin

Add `SmartEntityTick` as a separate Engine Plugin jar.

Default-safe behavior:

- Does not affect players.
- Does not affect all mobs by default.
- Throttles only safer categories by default:
  - dropped items
  - experience orbs
  - armor stands
- Only affects entities far from players.
- Can be configured from its own data folder.

### 4. Validation

- Compile VioletCore.
- Build runnable jar.
- Build SmartEntityTick jar.
- Smoke test startup and `/violetcore` commands.
- Release assets:
  - `VioletCore-26.2-v0.4.0.jar`
  - `VioletCore-source-patches-v0.4.0.zip`
  - `SmartEntityTick-1.0.0.jar`

## Non-goals for v0.4.0

- No Mixins yet.
- No unsafe chunk IO modifications.
- No default gameplay-changing optimizations inside the core server.
